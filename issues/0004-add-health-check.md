# ヘルスチェックエンドポイント GET /.ok を追加する

Created: 2026-03-27
Model: Opus 4.6

## 概要

HTTP サーバーに `GET /.ok` エンドポイントを追加し、200 OK を返すようにする。プロセスの起動確認やロードバランサのヘルスチェックに利用する。

## 根拠

zakuro (C++) では PR #74 でヘルスチェック用の `GET /.ok` エンドポイントが追加されている。運用時のプロセス監視やテストフレームワークからの起動確認に必要。C++ 版との機能互換性を維持するために対応する。

## 参考

- https://github.com/shiguredo/zakuro/pull/74

## 対応内容

### 1. HTTP サーバーにヘルスチェックハンドラーを追加する

- `GET /.ok` リクエストに対して 200 OK を返す
- レスポンスボディは空でよい
